# GlobalStudy 产品路线图（V0.5 → V4.0）

> 当前线上演示：手机 H5 + Node/Express API。
> 目标：从“留学申请 Demo”升级为“全球学校搜索与教育服务交易平台”。

## 产品总链路

C端：搜索 → 对比 → 收藏 → 建档 → 申请 → 材料 → 面试/考试 → Offer → 入学 → 付款/服务  
B端：注册认证 → 学校/服务搜索 → 佣金查看 → 代理协议 → 学生申请 → 结算  
S端：注册认证 → 发布学校/课程/服务 → 设置佣金 → 接收申请/订单 → 履约 → 结算  
平台端：审核 → 数据运营 → 订单/申请 → 佣金 → 结算 → 风控/审计

## V0.5 数据底座版（当前立即实施）
目标：让“全球搜索”具备可持续扩展的数据基础。

### 必做
- 国家、城市、行政区、轨道交通线路、站点、机场、火车站
- 教育阶段、学校类型、课程体系、语言
- 学校、校区、课程/项目、费用、奖学金、认证
- 数据来源、审核状态、更新时间、有效期
- 统一搜索 API 与筛选字典 API
- 第一批结构化区域：新加坡、上海、北京
- 第一批课程字典：IB、Cambridge、Pearson、IPC/IMYC、British、American/AP、Canadian、Australian、New Zealand、Singapore 等
- 所有测试学校继续明确标记“演示”，不虚构真实合作关系

### 验收
- /api/reference 能返回地区、阶段、课程等标准字典
- /api/schools 支持至少：国家/城市/地区/阶段/课程/语言/费用筛选
- 手机 H5 能组合筛选
- 数据结构可继续导入 10,000+ 学校而无需改表结构

## V1.0 全球学校搜索版
目标：第一次形成独立用户价值。

### C端
- 手机优先搜索首页
- 列表 + 地图
- 高级筛选
- 学校详情
- 最多 4 所对比
- 收藏、提醒
- 距离/地铁/通勤
- 费用与首年总成本
- 奖学金与助学金
- 匹配结果：符合 / 不符合 / 资料不足，不输出未经验证的录取概率

### B端
- 学校资源搜索
- B端专属招生政策与佣金标签
- 收藏学校/课程
- 佣金对比
- 合作状态

### 验收
- 新加坡/上海/北京至少一批真实、可追溯来源的数据
- 搜索结果可复现、可解释
- 每个关键字段有来源和更新时间

## V1.2 会员商业化版
目标：验证用户是否愿意为搜索与数据付费。

- Free / Standard / Professional 套餐
- 搜索结果可见数量配置
- 会员期限、账号席位、优惠码
- B/C会员权限差异
- 后台定价配置
- 订单、支付状态、退款记录
- 会员转化漏斗

文档中的 SGD 200/6个月、SGD 500/12个月作为可配置测试方案，不写死。

## V1.5 Search → Apply 申请协同版
目标：完成真实申请闭环。

- 学生档案
- 家庭材料库
- 机构代建档 / 学生自助建档
- 客户归属与授权
- 个性化材料清单
- 多校材料复用
- 正式申请
- 补件
- 面试/考试
- Offer
- 入学确认
- 申请状态机与时间线
- 通知与待办

## V2.0 S2B2C 商业协同版
目标：把“申请”变成“可结算业务”。

- B/S端认证
- 学校/机构代理协议
- 佣金规则引擎
- 学费比例佣金
- 固定人头佣金
- 阶梯佣金
- 绩效 Bonus
- Retainer / 区域代理费
- 续读佣金与复合模式
- 招生绩效
- 应收 / 应付 / 已结算 / 冲回
- 发票与结算记录

关键原则：佣金必须绑定供应方 + 产品/课程 + 批次 + 渠道 + 合同版本 + 触发条件。

## V2.5 学生住宿 Marketplace
目标：增加第一类高相关教育服务。

- 宿舍 / 学生公寓 / Homestay
- 房型、床位、库存
- 地图、学校距离、地铁距离
- 图片/视频
- 预订、入住、退宿
- 监护人服务
- B端分销
- 固定金额 / 租金比例 / 阶梯 / 续租佣金

## V3.0 教育服务 Marketplace
目标：从学校搜索扩展到全球教育资源撮合。

- 合作办学
- 2+2 / 3+1 / 1+3 / Pathway
- 双学位 / 联合学位 / 学分互认
- 语言培训
- 翻译
- 签证辅助
- 接机
- 学生服务
- B2B合作学校搜索
- 服务订单与供应商结算

## V4.0 教育金融（单独立项）
目标：只在持牌合作和合规方案明确后推进。

第一阶段仅做：
- 贷款产品展示
- 资格初筛
- 转介/跳转
- 线索归因

后续才考虑：
- 正式贷款申请
- 放款
- 还款
- 风控
- 反欺诈
- 贷后管理
- 金融佣金结算

## 当前开发顺序
1. V0.5 数据模型与参考字典
2. V0.5 搜索 API
3. V1.0 手机 H5 高级筛选
4. 导入真实学校数据
5. 做学校详情/对比/收藏
6. 完成验收后再进入 V1.2

## 不允许提前做
- 不先做复杂贷款
- 不先做完整住宿库存系统
- 不先做大而全微服务
- 不把演示数据伪装为真实学校/合作关系
- 不用 AI 生成未经验证的学校事实、佣金或录取概率
