## 4. 数据质量规则
- 真实学校必须有 source_url 或供应商证明。
- is_demo=true 的数据必须在前端显示“演示”。
- verified_status: draft / pending / verified / expired / rejected。
- 学费、截止日期、奖学金、招生要求必须带 verified_at。
- 过期信息不能自动作为当前事实展示。
- 不通过 AI 补齐缺失学校事实。
- 用户文件提供的是结构和字典基础，不等于真实学校供应关系。

## 5. API

### GET /api/reference
返回：
- countries
- cities
- districts
- educationStages
- curriculumFamilies
- curricula
- languages

### GET /api/schools
参数：
- q
- country
- city
- district
- stage
- curriculum
- language
- institutionType
- minFee
- maxFee
- scholarship
- boarding
- transitStation
- verifiedOnly
- page
- pageSize

### GET /api/schools/:id
返回学校详情、校区、课程、费用、奖学金、来源信息。

### GET /api/programs
可按 institution / stage / curriculum / fee / language 筛选。

## 6. 手机 H5 V0.5 交互
搜索首页优先展示：
1. 国家/城市
2. 教育阶段
3. 课程体系
4. 关键词

高级筛选放 Bottom Sheet：
- 区域
- 地铁/交通
- 语言
- 学费
- 学校类型
- 住宿
- 奖学金

结果卡片：
- 学校名称
- 城市/区域
- 教育阶段
- 课程体系
- 教学语言
- 学费区间
- 最近交通
- 是否有住宿/奖学金
- 数据更新时间
- 演示/已验证标识
