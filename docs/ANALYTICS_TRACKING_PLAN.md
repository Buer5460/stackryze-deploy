# GlobalStudy 访客统计方案

## 运营问题

- 哪些入口带来访问，访客主要浏览哪些客户端页面？
- 学校详情、服务详情、申请和住宿预订等内容入口的点击情况如何？
- 访问与点击是否推动了需求提交、注册或演示咨询？
- 运营排查某个访问行为时，对应访客的 IP 与匿名活动路径是什么？

## 事件表

| 事件 | 触发 | 记录字段 | 运营用途 |
| --- | --- | --- | --- |
| `page_view` | 打开受支持页面且已同意统计 | 页面、时间、IP、匿名访客编号、格式受限的 UTM 来源标签 | 入口和页面流量 |
| `content_clicked` | 点击有标记的内容或可识别链接 | 页面、点击项、公开内容编号 | 热门内容、页面路径 |
| `cta_clicked` | 点击带 `data-track-type="cta"` 的行动按钮 | 页面、行动项、公开内容编号 | 转化入口效果 |
| `form_submitted` | 提交有稳定 `id` 或 `data-track-key` 的表单 | 页面、表单标识 | 表单完成量；不记录输入值 |
| `search_submitted` | 学生端目录搜索成功返回结果 | 页面、搜索入口标识 | 搜索使用量；不记录搜索词 |
| `signup_completed` | 由页面在注册成功后显式埋点 | 页面、固定注册方式标识 | 注册漏斗；当前无用户注册流程接入 |
| `demo_requested` | 由页面在演示咨询成功后显式埋点 | 页面、固定来源标识 | 演示咨询漏斗；当前无咨询表单接入 |

## 已接入的内容点击

学生端学校详情、学校申请、供应商详情、服务选择和住宿预订按钮记录固定点击项，以及相应公开目录记录编号。页面内其他按钮只有在带 `id`、`data-action` 或 `data-track-key` 时才会记录；不保存按钮文字或用户输入。

要扩展某个内容点击，在页面元素上添加稳定的标记，例如：

```html
<button data-track-type="cta" data-track-key="student_apply" data-content-id="INS-123">申请</button>
```

`data-track-key` 只应使用固定代码名，`data-content-id` 只应放公开目录编号。不要把姓名、账号、手机号、邮箱、搜索词、表单内容、订单编号或申请编号放进标记。

## 数据与隐私边界

- 访客必须主动选择“同意统计”后才创建随机访客编号并发送统计事件；拒绝不影响使用。
- 同意状态保存在 HttpOnly、SameSite=Strict 的第一方 cookie 中，有效期 30 天。服务端不接受客户端提交的 IP。
- 仅记录 IP、受控页面路径、固定事件名、点击标识、公开内容编号及有限格式的营销来源标签；不保存完整 URL、查询参数、来源页、User-Agent、账号 ID、姓名、电话、邮箱、搜索词或表单值。
- 不把统计访客与平台登录账号关联。管理端只允许拥有 `admin:analytics` 权限的超级管理员和运营管理员查看 IP 与访客活动。
- 既有的账号登录/安全会话记录属于平台认证功能，可能按账号记录登录 IP；它与本统计模块分开处理，需在平台账号服务的完整隐私告知中说明。
- 明细保存 30 天；访客可以通过“统计设置”撤回同意并删除关联事件，管理员也可删除单个访客记录。
- 未配置运营主体全称和隐私联系渠道，或未显式设置 `ANALYTICS_ENABLED=true` 时，埋点关闭。
- 网站托管商、反向代理或服务器可能另行生成连接安全日志；应在各自隐私告知、访问权限与保留规则中单独管理。

## 指标定义

- 访客数：选定周期内出现的去重随机访客编号数，不代表实名个人数。
- 页面访问：`page_view` 事件总数。
- 内容点击：`content_clicked` 与 `cta_clicked` 事件总数。
- 搜索提交：`search_submitted` 事件总数，不代表具体关键词。
- 表单提交：仅统计 `form_submitted` 数量，不包含表单字段。
- 热门内容：按 `data-track-key` 和公开 `content_id` 汇总点击次数。

项目当前未开放医疗与金融供应商模块；两类路径不在埋点允许列表中，并由 `GS_DISABLED_MODULES=MEDICAL,FINANCE` 保持关闭。
