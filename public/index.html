接真数据
目标很简单：技术只需要给一个安全的只读数据源，不需要改现有支付系统，也不需要专门开发 AI。

技术需要提供什么

1. 交易数据交易时间、商户ID、交易金额、手续费、交易状态
2. 商户数据商户ID、商户名称、代理ID、状态
3. 代理数据代理ID、代理名称、上级代理（如有）
4. 分润数据代理ID、分润金额、日期/结算时间
5. 成本 / 费率通道成本、成本费率，或系统已经计算好的利润字段
6. 关联关系商户、代理、交易、分润之间用什么ID关联

接入方式（按优先级）

1
只读副库 / 报表库（推荐）
最省技术工作量。只允许 SELECT，最好只开放指定 View。
2
现有查询 API
如果系统已经有接口，直接给 API 文档 + 只读 Token 即可。
3
Excel / CSV
如果暂时不方便开放数据库或 API，先导出数据也能把 MVP 跑起来。

安全要求

✓
只读
只允许 SELECT，不给写权限。
✓
优先副库 / 报表库
不直接连接生产主库。
✓
指定表 / View
只开放老板需要的数据。
✓
IP 白名单
只允许 Data Gateway 访问。
✓
敏感字段不开放
身份证、银行卡号、密钥等默认不返回。
第一阶段只做“查 / 分析 / 预警”。 不接退款、改费率、打款、删除商户等写操作。

我们接通后会给老板看什么

经营指标异常监控
今日交易流水商户流水下滑
今日手续费收入今日无交易商户
今日通道成本连续多日无交易商户
今日代理分润代理分润排行 / 异常
今日公司利润核心商户异常
